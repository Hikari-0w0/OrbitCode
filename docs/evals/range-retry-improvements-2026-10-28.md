# 大文件分段读取与请求退避（2026-10-28）

本次只修复两个可由源码确认的缺口：指定行范围仍受整文件 512KiB 上限限制，以及可恢复模型请求错误仅等待 100–500ms 就重试。实现不识别评测题目、目标仓库或特定模型，不增加运行时依赖。

## 大文件分段读取

`read_file` 指定 `start_line` 或 `end_line` 时，通过 Workspace 边界按 64KiB 块读取文件，只积累所选行。扫描容量和返回容量分别限制为 32MiB、512KiB；单次最多 2000 行的原约束保留。未指定行范围的完整读取仍限 512KiB，避免意外占满上下文。

流式扫描仍遍历整文件，用于严格 UTF-8 校验、真实总行数和兼容原行为的整文件文本 SHA-256；不会把未选中的正文保存在返回结果中。保留 CRLF、末尾无换行及空文件语义。文件路径与受保护路径继续经过 Workspace 校验，打开后核对文件身份，结束后复核路径和身份；支持取消并在结束时关闭文件句柄。

分段结果使用独立类型，不提供整文件替换所需的顶层快照身份，不能直接传给 `replaceSnapshot`。超过扫描容量、选中内容超过返回容量或读取期间发生可检测的文件变化时返回结构化错误，不把不完整结果冒充完整快照。扫描仍有 I/O 成本，单条超长行也可能超过返回容量。

## 模型请求退避

可重试错误使用带随机抖动的指数退避：首次等待 0.5–1 秒，后续指数增长，退避基数最多 30 秒。HTTP 响应支持解析 `Retry-After` 秒数或常见 HTTP 日期，实际等待不短于服务端要求；要求超过 60 秒时交还原错误，不提前重试，也不无限占用请求。HTTP 错误响应主动释放，不读取或记录错误正文。

没有增加重试次数。仍只对原本可恢复、尚无语义输出的错误重试；每次实际请求继续经过原请求预算接纳。退避等待可由调用方取消，Agent 总时限仍通过同一取消信号生效。不自动重放工具副作用，不切换模型。
