# 子 Agent 真实模型全面测试

日期：2026-10-21。用户明确要求使用真实模型全面测试。本轮固定现有运行时，扩大覆盖并独立取证，没有修改 `src/`、内置角色或安全策略；仅新增/纠正评测脚本和记录。源码前后491项哈希核对中，变化仅为两个评测脚本。

## 结论

覆盖56个场景实例，合计60次尝试：原始结果 **56通过、4次夹具/编排失败**。四项修正后分别在新目录补测通过，全部原始失败保留；补测已包含在60次中，不能写成60/60首次通过。

运行控制、文件/权限边界、结果交接及预算的已测路径未发现新增运行时失效。**源码解释不能判为全面语义通过**：人工抽查3份答复均有需要限定的引用或推断问题，一份Web答复把未核实的会话管理服务列入聊天执行链。自动场景通过只证明其明确的工具、状态、文件或进程断言，不证明全部自然语言结论。

本批57次场景尝试实际调用模型，2次token预算检查在发送前拒绝，1次Web启动失败尚未调用模型。真实模型为本地配置 `deepseek-flash`；未推广到所有模型或厂商。模型调用、工具、本地文件和进程均经过真实运行时，MCP服务本身使用本地可控协议夹具，未调用第三方公网MCP服务。

## 固定条件与范围

- 隔离Workspace和数据目录，不复制用户密钥/配置到测试文件。配置凭据经环境变量提供，日志按当前凭据精确脱敏。
- CLI通过tmux中的实际SessionController运行；Web通过独立生产Next服务的HTTP/SSE，另有实际agent-browser页面输入、委派、等待及正文读取。
- 常规父24轮、子20轮、并发3、输出8192；使用实际角色上限。异常场景单独收窄1轮或1分钟总时限，预算场景显式降低共享额度。
- 成功依据包括实际工具调用、独立Node契约断言、真实文件、原始失败码、进程存活、正文哈希及检查点。模型自称完成不构成验收通过。
- 本轮保留失败并诊断，不针对样本修改运行时或削弱安全边界。

## 四次失败及补测

### 1. 最大轮数判据错误

原评测要求子任务maxIterations=1时仍成功读取文件，实际返回max-iterations、工具cancelled且无副作用。当前实现明确在最后允许轮次不执行新工具：`src/core/agent-loop.ts:349`；既有确定性测试 `src/core/agent-loop.test.ts:448` 也约束执行次数为0。

因此失败属于新增评测与现有契约冲突。原 `boundaries/results.json` 保留失败；`max-iterations-corrected/` 的新样本验证同一1轮上限、工具不执行、结构化cancelled和sideEffect=none，并通过。另单独重跑AgentLoop测试作为判据依据，没有修改终止行为。

### 2. Web修复旧夹具误启开发模式

旧脚本调用Web夹具时省略serverMode，尝试启动next dev，与用户已有开发服务发生锁冲突。没有连接用户原有服务，也没有停止它；该样本未调用模型。

仅将 `run-report-free-real-evals.ts` 的评测入口显式改为生产start，在 `repair-web-corrected/` 新样本中完成真实子任务修复和独立断言。初次server.txt、非零退出码和results保留。

### 3. 浏览器编排收口超时

首次页面输入、模型委派和子文件读取已完成，面板显示terminal/committed；但自动等待错误地使用不存在的aria-label选择器，并在排查期间超过临时夹具6分钟的收口窗口。不能据模型成功改写整个浏览器样本的失败。

新样本 `browser-corrected/` 改用实际观察到的textarea就绪条件，并将人工编排窗口延至15分钟；实际经页面选择定义式/仅委派、输入请求、发送、查看任务与agent result正文，再核对原生日志。父仅调用agent，子实际read_file，完整标记一致；最终browser2-errors与console为空。两个样本均保留，运行时和生产页面代码未改。

### 4. stdio MCP日志判据错误

首次真实模型已调用子任务MCP echo，但临时评测把JSONL日志每行整体当作方法名字符串。该日志实际为 `{method,id}`，因此字符串includes判据失败。

修正仅发生在新临时脚本的解析器，原日志未修改；`integrations-corrected/` 新样本通过。HTTP与最终stdio样本均实际观察到initialize、tools/list、tools/call各1次；子结果verification=observed，只说明外部工具调用返回，不推导整任务已验证。
