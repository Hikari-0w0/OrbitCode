## Agent 对照编排

使用同一本地对话协议替身，对 5 个问题分别运行关闭/开启检索两组，每组每题 3 次，总计 30 次进程正常结束。这里的“正常结束”仅证明进程协议，不代表答案正确或任务通过；替身固定回复不适合质量比较，报告中的人工评分保持 pending。

评估脚本另补充保存工具证据、向量构建用量和查询结果，并以额外 2 次替身运行核对报告字段。最终脚本将固定语料复制到临时工作区，预创建只读 Plan 会话，问题标注文件不进入 Agent 工作区；运行结束清理临时设置与会话，仅保留指定的私密报告。

## 保留的失败与修复

1. 初次单测对 BM25 第一名的预期没有考虑长度归一化；人工复核后修正夹具断言，算法不为断言改变。
2. 临时目录在 macOS 上含系统路径别名，初始目录检查误拒绝；保留目录/文件类型与权限检查，修正对受信任父目录别名的处理。
3. 零等待构建锁在回收已退出 owner 后仍返回 busy；增加最多 80 ms 的有界锁回收窗口，并通过双进程崩溃恢复测试。
4. 第一轮浏览器复用会话时，替身重复生成工具 ID 导致保存失败；改为唯一 ID，并在新会话验证持久化成功。
5. 完整回归一轮出现 CLI 在 500 ms 信号触发前尚未完成启动的失败（807/808）；定向复测通过，随后将 TypeScript 解析器改为构建时加载。后续完整回归通过，没有放宽信号或权限测试。
6. npm 12 使用 --prefix 的临时生产安装检查误判项目名；改为在临时目录执行 npm ci，生产安装验证通过，没有改动锁文件内容来绕过检查。
