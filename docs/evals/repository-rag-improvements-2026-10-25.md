## 本轮修改

1. `mode-policy.ts` 将只读 `search_knowledge` 纳入 Plan 白名单，继续拒绝文件写入与命令。补充定义公开、实际执行及独立 CLI Plan 会话测试，避免只验证工具注册。

3. 检索工具向模型提供 `citation` 与逐行 `sourceLines`；原始 excerpt、内容哈希和索引不变。结果预算按格式化后的实际片段 JSON 计算，避免新增行号绕过预算。此展示改进不能保证模型自行引用正确。
4. 有限轮数主 Agent 在最后三次请求末尾收到临时 system 预算提示，要求核对直接证据、避免重复读取、如实说明未完成项；提示计入上下文预算，不写入会话历史。最大轮数、工具定义、Tool Calling 协议、硬停止与子执行限制不变，无限轮数保留原周期复核。

未新增依赖；保留用户已有管理鉴权修改。此前已批准的功能范围、权限边界和验收标准不变。
