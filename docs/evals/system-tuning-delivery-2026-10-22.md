## 已实施的变化

| 方向 | 改动及作用 | 保留边界 |
| --- | --- | --- |
| 文件遍历 | 按需产出文件；根据 glob 前缀跳过不可能命中的目录；修复跨目录 `maxEntries` 上限，保留稳定完整路径排序 | 仍忽略受保护路径、默认忽略目录及符号链接；没有扩宽 Workspace 权限 |
| 搜索预览 | 长行预览围绕命中位置，必要时携带 `textStartColumn`，避免命中了却看不到目标 | 仍为字面量搜索；行列使用现有字符串计数规则 |
| 分段读取 | `read_file` 增加从 1 开始、包含端点的 `start_line/end_line`；单次最多 2000 行，只有起始行时默认 200 行；保留原换行 | 省略行参数仍返回原完整结构；文件仍受 512KiB 上限约束，内部仍读取完整安全快照，优化的是模型上下文与往返，不是磁盘流式读取 |
| 子任务交接 | 分段读取事实携带实际范围、全文快照指纹和全文字节数；同路径最新读取替换旧指纹 | 不把片段误记成全文，不保存原文到事实交接 |
| Web 任务状态 | 指示器与面板共享一套任务请求；关闭面板只请求计数摘要；活动时 1.5 秒、空闲时 15 秒，前次完成后再计时 | 隐藏页面取消请求、恢复时刷新；手动刷新合并在途请求；角色目录只在面板挂载或手动刷新时获取；摘要保留原会话权限与生命周期检查 |
| 侧栏布局 | 低高度时内容保持自身高度并允许侧栏滚动，避免会话操作与工具区域重叠 | 不增加移动端布局范围 |
| 构建追踪 | 对实际运行时数据路径添加局部 Turbopack 注解，内置角色与 Skill 保持显式打包 | 不扩大忽略目录或移除安全校验 |
| 委派参数恢复 | `agent.start` 收到多余字段时，明确说明 `timeoutMs` 仅用于 `wait`；schema 同步提示 | 仍严格拒绝非法参数，不为通过样本放宽校验 |

核心文件包括 `src/tools/workspace.ts`、`glob.ts`、`search-code.ts`、`read-file.ts`、`src/runtime/child-execution/handoff.ts`、`src/components/task-polling.ts`、`use-agent-tasks.ts` 及 `src/web/agent-task-http.ts`。
