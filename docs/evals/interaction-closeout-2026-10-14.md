## 本次修正

- CLI 在资源清理失败时输出 failed 和非零退出码；输入等待阶段的 SIGINT 输出 cancelled/130。补齐保存、日志、清理失败及独立子进程协议测试。支持单次 `--max-iterations`，不改写持久配置。
- Web 默认模型候选顺序与托管默认项一致，保持有效旧会话绑定。结束消息分开显示停止、验证和保存状态，保存失败后只重试保存。配置已持久化但旧连接清理失败时返回明确警告，不误报为保存失败。
- 管理接口限制请求体和未知字段；模型和 MCP 探测改为 operationId、SSE 订阅及取消，订阅前不发生外部动作，断流取消，终态唯一；本地管理会话独立，拒绝访问其他会话的操作。
- MCP 工具名称按配置秘密脱敏；设置变更只 reconcile 连接，不初始化新连接。停用空闲 stdio Server 后进程退出；旧活动租约仍可完成后排空。
- run_command 的参数说明明确自动返回 exitCode/stdout/stderr，避免模型追加 echo 覆盖失败退出码。验收规则与安全限制均未放宽。
