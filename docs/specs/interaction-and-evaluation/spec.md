状态：已批准
日期：2026-10-11
关联：[技术计划](plan.md) · [实施任务](task.md) · [验收清单](checklist.md)

> 四份文档均已获批准；实施与真实模型复测按任务和验收清单执行。

## 背景

用户希望通过界面管理模型、工作区、MCP 等配置，并能通过 CLI 输入任务、等待结果、判断 Agent 能力和持续改善效果。现有产品已有模型和工作区选择、会话恢复、审批和运行记录，但配置仍以手工文件为主。CLI 已接受管道输入并等待完整行执行，尚无面向自动化的单次结构化执行契约。现有模拟模型测试可验证程序行为，不能代替真实模型能力评测。

## 目标与交付边界

1. 新用户不手写配置文件即可完成模型、工作区配置及首次对话，MCP 为可选步骤。
2. Web 与 CLI 共用配置及 Agent 运行语义，配置变更不破坏历史会话或进行中的任务。
3. 单条 CLI 命令能够执行一个任务、等待终态并返回可关联的机器可读结果。
4. 建立程序回归、浏览器体验、真实模型评测及独立验收的完整链路。
5. 基于受控基线定位并验证具体改善，不能把最终回复或模型自评当成完成证据。

## 假设与方案选择

- 本轮面向单用户、本机运行的 Web 与 CLI；不提供远程多用户管理服务。
- 保留现有模型协议和参数能力，不承诺新增厂商原生协议。工作区是服务端本地目录。
- 采用共享配置管理、界面编辑和私密本地持久化；旧配置显式导入，保留兼容读取入口。相较直接在页面改写多份 YAML，该方案能统一版本、凭据与错误处理；相较云端配置服务，无须引入账号和同步系统。
- 按“配置基础 → 首次使用 → MCP 与运行体验 → 评测与改善”分阶段交付，但属于同一轮范围。
- 真实模型评测使用运行者显式提供的未入库凭据与预算，自动测试仅使用合成凭据。真实调用只在明确评测预算内执行。

## 功能需求

### 配置与首次使用

- F1：无配置、配置损坏或全部资源不可用时，用户仍能进入设置、查看历史会话并获得明确的修复路径；首次使用可完成模型、工作区设置后开始对话。
- F2：用户可新增、编辑、重命名、停用及设置默认模型，配置密钥或环境变量引用。常用项直接展示，高级项折叠。分别显示已配置、未测试、测试中、测试成功和失败；测试记录带时间，编辑后过期。连接测试有超时、可取消，不执行 Agent 工具。
- F3：用户可添加本地目录、验证可访问性、重命名、设置默认工作区与移除记录。展示授权根目录；路径失效时给出原因。移除记录不删除目录或历史会话，改变根目录须新建工作区身份。
- F4：用户可管理用户级及工作区级 MCP，支持已有的 stdio/HTTP 参数、凭据、启用/停用、连接测试、重连、断开与工具列表。展示作用域、覆盖来源、连接状态和错误。保存不连接；连接、工具发现与工具调用的结果必须区分。
- F5：支持旧配置预览导入，报告重复项、缺失凭据和不支持字段，确认后一次性保存；不修改源文件、不静默导入或启动进程。界面显示实际配置来源，兼容入口与托管配置不隐式混合。
- F6：用户可设置默认权限模式、默认模型/工作区、最大轮数和总时限。保存后两端下一轮使用同一版本；进行中的运行保持原快照。重命名保持身份，停用/移除后的旧会话仍可阅读，并可选新绑定创建后续会话；不重写历史记录。

### 对话与自动化

- F7：对话区明确展示当前绑定、等待模型、工具执行、等待审批、停止与保存状态；错误提供相关设置或重试入口。切换模型或工作区说明新建会话。结束摘要分开呈现停止原因、Agent 所列验证和未完成事项，不宣称独立验收成功。
- F8：提供单次 CLI 执行，接受 prompt 文件或标准输入，支持选择模型/工作区或恢复会话。自动等待终态及持久化、清理完成后退出，支持 JSON/JSONL、版本字段、退出码、运行标识与超时取消；旧交互入口保持兼容。
- F9：非交互执行不得等待无法处理的人工审批，也不能默认放行。遇到审批请求时停止该轮并报告授权阻塞；已有允许规则仍走正常权限校验。支持显式指定受控授权策略，拒绝规则始终生效，执行记录包含策略标识和人工干预情况。
- F10：CLI 评测可指定隔离存储和临时工作区，隔离配置、会话、日志、上下文、权限及 MCP；默认不读取日常用户配置和项目外凭据，不通过修改 HOME 实现隔离。

### 评测与改善

- F11：维护可重复执行的单元、契约、模拟模型端到端及浏览器完整流程；覆盖异常、权限、配置并发更新与 Web/CLI 一致性。
- F12：建立固定任务集及执行器，固定任务文本、文件初态、模型/配置和版本，每次创建独立工作区。CLI 结束后独立检查实际文件、命令与禁止副作用，结果为通过、失败、阻塞或无法判断，且与 Agent 自评分开。
- F13：评测报告记录运行标识、证据完整性、成功率、失败类型、耗时、工具次数、可用用量和人工干预。缺失值不记为零。改善前后同条件复测，一次调整一个主要因素，报告质量与效率变化及未覆盖范围。

## 非功能需求

- N1：凭据只保存在未入库的本地私密存储或环境变量；列表、日志、错误、模型上下文、截图及普通导出不得包含明文。设置修改操作须有本地会话与同源保护。
- N2：复用共享 runtime、工具、权限、会话和沙箱，不在页面或评测器复制 Agent Loop，不新增 Agent 框架或托管执行能力。默认零新增运行时依赖。
- N3：配置写入具备跨进程并发冲突检测和原子提交；损坏配置不可静默清空、覆盖或回退成另一套配置。
- N4：保持既有路径边界、Plan 模式约束、审批复检、取消与资源清理；连接或测试失败不得自动放宽权限。
- N5：表单有字段标签、键盘操作、就地错误及保存反馈；空态、载入、失败和禁用态均可理解，错误不只依赖颜色。
- N6：所有外部等待有界；评测预算至少约束轮数、总时长与执行次数，缺失价格或完整 usage 时不承诺精确费用。

## 不做的事

- 云同步、账号、多用户远程管理、系统密钥链集成和 MCP OAuth。
- 新模型协议、MCP Resources/Prompts/Sampling、自动安装 MCP 软件、后台自动重连或重试有副作用调用。
- 任意文件浏览器、可视化权限规则编辑器和完整可观测性平台；本轮工作区通过输入/粘贴本机路径添加。
- 自动根据评分改写并发布 Agent；本轮改善须由明确证据驱动，不预设 Prompt 就是根因。
- 把所有参数都搬到页面；高级开发配置保留现有方式。原始会话导出仍可能包含用户代码与正文，不能冒充全面脱敏导出。

## 验收标准

| 编号 | 覆盖 | 给定、操作与预期 |
| --- | --- | --- |
| AC1 | F1、N5 | 空配置启动，通过设置新增模型/工作区并完成首轮；损坏配置仍可打开设置和历史记录，未经恢复操作不覆盖损坏文件。 |
| AC2 | F2、N1、N6 | 新增/编辑/停用/设置默认模型；分别测试有效、无效凭据及超时取消；状态准确，修改后旧测试失效，所有返回不含密钥。 |
| AC3 | F3、N4 | 添加合法目录并使用；不存在/不可访问路径被解释性拒绝；改名保持会话绑定，移除不删除实际文件，旧会话仍可读。 |
| AC4 | F4、N4 | 两种 MCP 传输完成配置、审批、发现工具与断开/重连；单纯保存零进程启动和零网络调用；停用/冲突/故障状态明确，不宣称发现等于调用成功。 |
| AC5 | F5、N3 | 导入合法旧配置，预览冲突并确认后保存；无效项导致整批不落盘，源文件不变，兼容读取来源可见。 |
| AC6 | F6、N2、N3 | 两端加载相同配置版本；运行中编辑后当前轮不变、下一轮生效；并发保存冲突不丢更新；停用资源历史可读且不能继续误用。 |
| AC7 | F7、N5 | 浏览器完成切换、审批、取消、保存失败重试及刷新恢复；摘要区分停止与验证，无错误覆盖层和未处理控制台异常。 |
| AC8 | F8、N6 | 文件/stdin 单次输入，JSON 可解析、JSONL 有序且仅一个终态；明确输出失败、超时、取消和保存失败；结果可关联对应日志，旧交互入口仍可用。 |
| AC9 | F9、N4 | 非交互遇到审批有界结束且未执行被阻止动作；受控策略允许项正常执行、deny 不可覆盖，记录策略和阻塞信息。 |
| AC10 | F10、N1 | 两次隔离执行不读取/改写日常配置、记录或用户权限；未显式选择的 MCP 不启动，子进程不继承无关模型密钥。 |
| AC11 | F11、N2 | 程序测试及浏览器流程覆盖配置与执行闭环，模拟故障可稳定复现；真实模型测试不混入默认自动测试命令。 |
| AC12 | F12、N4 | 从固定初态运行任务，独立验收识别正确修改、伪完成、越界尝试和验收器故障；验收代码不可被被测 Agent 修改而影响判分。 |
| AC13 | F13、N6 | 生成版本明确的基线和前后对比；包含重复运行及失败分布、缺失证据和未验证项，不用自评或单次成功替代任务通过率。 |
