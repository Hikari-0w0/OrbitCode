- 每项记录日期、仓库 revision、命令、退出码、关键观察、脱敏证据位置；失败写明预期、实际和下一步。
- 单元与协议测试只用合成凭据及本地替身。真实模型仅通过用户已有、未入库的环境配置运行，测试文件不含真实密钥；不显示环境变量全集或鉴权头。
- 模型或浏览器环境不可用时保持未勾选，写明阻碍；不以替身成功代替语义质量或真实页面验收。
- 作业、查询和人工标注均记录实际版本；涉及文件变化场景另外保存受控夹具前后内容，不能把会话检查点当文件快照。
