## 背景

当前 Web 与 CLI 共用 Agent 循环、会话创建、工具权限和持久化流程。独立 Skill 已支持历史选择、上下文引用迁移、独立消息与完成验证以及有界结果汇总，但执行等待、取消、审批和资源释放仍绑定父轮次。其历史来源是父轮次开始时的已保存上下文，不能直接代表委派时的实时快照。

本阶段在上述基础上提供按角色委派和 Fork，并建立运行时内的后台任务生命周期。子执行过程保留在子上下文中，主 Agent 接收可追踪的结构化结果；上下文独立不代表工作区文件独立。

## 目标

- 主 Agent 通过统一工具创建定义式或 Fork 式子任务，并查看、等待、取消任务。
- 子任务具备独立状态、受限权限、明确预算和可靠清理，后台执行可跨越父轮次结束。
- Web 与 CLI 共用行为、任务状态和结果交付语义。
- 提取现有独立 Skill 的通用子执行能力，保持既有 Skill 行为兼容。

## 假设与待审批决策

1. 本轮作为一个闭环交付：角色定义、子执行、后台生命周期和双端控制相互依赖；不单独交付只能创建而不能控制或回收的后台任务。
2. 统一工具通过操作参数提供创建、查看、等待和取消；创建时通过类型参数区分定义式与 Fork。创建立即返回任务 ID；“前台”指主 Agent 随后等待同一任务，不把创建调用挂起至子任务完成。
3. 定义式必须选择角色；Fork 可选择角色，不选时继承父指令与模型背景，仍强制应用子执行限制。选定角色只能叠加限制，不能解除父约束。
4. 初始内置角色提供通用执行、只读探索、只读审查三类；具体名称和精确工具集合在技术计划中确定。角色定义通过本地文件维护，本阶段双端提供列表、来源及诊断，不增加角色编辑器。
5. 默认每父轮次最多创建 4 个委派任务；每运行时最多保留 32 个未清理任务记录、最多并发执行 2 个子任务；每任务最多 16 次模型迭代，接纳至终止最多 5 分钟，前台单次等待默认最多 30 秒。均允许通过两端共用配置调整为有限正值，且服从更严格的角色及父级配置上限。排队、审批、锁等待和模型执行都计入任务时限；不继承父轮次剩余时间作为后台任务的寿命。
6. 同一工作区内由 OrbitCode 调度的潜在写入保守串行化，覆盖父 Agent、子 Agent 与独立 Skill；无法判定写入范围的命令和外部工具按潜在写入处理。读取可并发，不承诺读取快照一致性。跨进程外部编辑不在锁保证范围内，应保留现有冲突检测和验证边界。
7. 后台完成只入队并通知界面，不自行发起新模型请求。主 Agent 活跃时在安全边界消费；父轮次已结束时等待下一次用户触发的主轮次。CLI 单次运行结束即关闭其运行时，未完成后台任务被取消并在输出中说明；交互 CLI 和 Web 在运行时存活期间可继续持有任务。

## 功能需求

- **F1：统一委派入口。** 提供一个参数化 Agent 工具，按类型选择定义式或 Fork，按参数选择角色，不按角色新增工具。创建成功返回唯一任务 ID、所属父会话、类型、初始状态和有效预算；未知角色、无效参数、无效模型或容量不足返回结构化错误，不偷偷回退或启动替代任务。
- **F2：角色定义与解析。** 使用 Markdown 加 YAML frontmatter；元信息包含角色名、用途说明、工具白名单、工具黑名单、模型配置名或继承、最大轮次、权限模式。正文在整个子生命周期内持续生效，受系统约束和父级权限限制。项目级高于用户级、高于内置，同名整体覆盖；同层重名和非法定义可诊断，高优先级坏定义不得静默回退。运行中使用已解析定义快照，修改只影响后续创建。读取定义不执行脚本、不连接 MCP。
- **F3：定义式上下文。** 从空白对话历史、角色指令及明确子任务输入启动；保留必要的系统规则、授权工作区和项目约束，但不自动复制父对话历史、父执行状态或父工具结果。
- **F4：Fork 快照。** 在委派发生时获取父会话当前已有的完整消息组快照，包含当前用户输入及本轮此前已完成的工具交换。排除正在执行且结果尚未齐全的整个助手工具调用组，包括同组其他调用，不产生孤立调用或孤立结果；不伪造结果补齐。保留既有摘要，不声称恢复已被压缩的原始历史。快照完成后的父历史变化不影响子历史。Fork 固定后台运行，显式请求前台 Fork 返回参数错误。
- **F5：引用迁移。** Fork 的卸载内容迁入子上下文，子任务不得通过旧引用访问父存储。可迁移的结构化引用保持可读；文本中无法迁移的引用明确标注不可用，不悄悄指向不同内容。超出迁移容量、内容缺失或消息组损坏时拒绝启动并清理资源，不静默截成最近历史。
- **F6：请求前缀与模型。** 使用现有 OpenAI 兼容 Provider 配置，允许角色继承或选择已有配置，不引入固定模型档位。Fork 尽量保留兼容的系统背景与历史顺序，避免无意义重写稳定请求前缀；权限过滤、引用安全和正确消息配对优先于前缀复用。缓存命中仅依据服务返回的 usage；缺失字段显示未知，不能由耗时或前缀相同推断命中，未命中不影响正确性。
- **F7：独立状态与复用。** 子 Agent 独立拥有消息、上下文存储、权限追踪、完成状态、取消控制和用量统计；共享不可变配置和受管理基础设施，不共享可变会话状态。复用已有循环、会话创建和独立 Skill 的历史选择、迁移、汇总能力，提取通用子执行基础设施。既有独立 Skill 仍保持其前台等待、历史范围、审批与父预算语义，不自动变成后台任务。
- **F8：权限交集。** 有效权限不超过委派时父有效权限上限，叠加角色白名单、黑名单、角色权限模式、父 Plan Mode、激活 Skill 限制和后台约束，拒绝优先。父后续扩大权限不自动扩大子权限；可观察到的撤销或收紧在后续操作中生效。子授权记录不反向授予父或兄弟权限。角色指令、模型输出、共享 Skill 均不能绕过限制。前台可通过带子任务身份的独立审批请求获得父权限范围内的单次授权；后台和非交互执行遇到需审批操作直接返回结构化拒绝。
- **F9：禁止递归。** 子 Agent 不得调用任何委派或子任务编排操作；不得通过独立 Skill 间接启动下一层子执行。工具展示和执行校验均须限制，伪造工具调用也被拒绝。共享 Skill 可以加载，但加载入口及激活后的工具行为均服从子权限边界；原有 Skill 加载豁免不能突破子级黑名单。
- **F10：后台任务所有权。** 运行时任务管理能力持有子执行需要的上下文、权限状态、MCP 连接租约、进程资源、状态、结果与用量。任务至少可区分排队、运行、终止及结果待投递状态；终态有唯一停止原因。父轮次正常结束或释放其资源不得破坏子任务；任务终止后关闭执行资源，保留受容量约束的结果供查看和交付。
- **F11：等待与转后台。** 定义式支持显式后台、前台等待、等待超时自动结束等待和用户手动结束等待。三种后台路径保持任务 ID、执行实例、已执行工具与原截止时间不变，不重跑、不续期。转后台后尚未获准的审批被撤销并转为结构化拒绝；迟到批准无效，已开始的授权操作按原任务取消与时限规则处理。等待已终止任务立即返回已有结果。
- **F12：取消与关闭。** 结束前台等待只解除等待，不取消任务。显式取消任务停止排队或运行、取消审批和子进程并保留部分结果与副作用；重复取消和完成竞态不能产生多个终态。停止父生成或浏览器断开结束等待，已接纳子任务继续按其生命周期运行。关闭运行时拒绝新任务、取消未完成任务并回收所有资源；不会跨重启恢复或自动重放。清空或删除父会话须取消其子任务并使旧结果失效，不能写入同 ID 的新会话世代。
- **F13：结果队列与安全消费。** 创建调用只承担接纳确认；后台完成生成带任务身份的结果事件入队。主 Agent 仅在工具调用组已配对、没有模型响应正在提交的安全边界消费，不能由后台回调直接修改父历史。父轮次已结束或租约不可用时保留待消费结果。结果不能伪装成已经返回过的创建工具调用的第二份结果。
- **F14：持久化与去重。** 结果进入父历史须持有现有写入租约并遵守版本检查。投递身份与父历史提交一致；保存失败保留待保存内容，重试保存不重跑子任务、不重复追加结果。查看、等待、重复完成通知和重新加载均不能造成重复投递。会话切换不跨会话投递；运行时关闭后允许丢失尚未保存的队列，界面须明确这一边界。
- **F15：结构化结果与验收边界。** 完成结果包含任务身份、停止原因、最终回复、工具失败、已知或可能副作用、验证状态和证据边界、用量及清理异常。正常最终回复只表示循环正常结束，不代表任务验收成功。可恢复工具拒绝或失败反馈给子模型；取消、运行上限、最大轮次、致命错误等停止执行并保留已有事实。摘要有界，截断可见且保留关键状态与证据入口；运行日志和子上下文不全量复制进父历史。
- **F16：双端管理。** Web 与 CLI 均可列出角色及诊断、查看当前运行时中的所属子任务、查看状态和结果、等待、手动转后台、取消。任务列表显示所属会话、类型、角色、时间、预算和投递状态；不可通过任意任务 ID 访问或取消其他授权范围的任务。等待不得阻塞用户取消或转后台操作。双端采用相同业务语义，不要求不同进程共享内存任务。
- **F17：预算与容量。** 约束父轮次创建次数、运行时任务数量和并发数、子最大轮次和总时限。并发满时有界排队，容量满时明确拒绝；排队到期不启动执行。前台等待不占用工作区写入锁。已完成且已投递记录按有界策略清理，待投递结果不能为腾空间静默丢弃。限制值和拒绝原因可观察，既有独立 Skill 与新子执行在共享资源上不能绕过并发限制。
- **F18：共享工作区协调。** 父 Agent、独立 Skill 和子 Agent 对同一工作区的潜在冲突写入统一协调，等待写入权限计入任务时限且可取消；未知副作用的命令和 MCP 操作不得绕过协调。持续运行且可能写入的进程在其存活期间保留相应占用或被明确拒绝，不能在启动返回时提前释放保护。只协调 OrbitCode 管理的操作，不宣称文件隔离、事务回滚或外部编辑隔离；副作用无法确定时结果标记可能，后续外部改动不能由旧验证结果证明正确。
- **F19：用量与运行记录。** 父与子请求分别计量，汇总时明确父自身、各子任务与总量，避免重复累计；覆盖模型执行和上下文压缩，请求失败及 usage 缺失保留可见信息。支持服务报告的缓存用量字段，缺失不补零冒充观测。记录父子关联、创建、等待方式变化、停止、投递及清理，日志不包含凭据。

## 非功能需求

- **N1：架构一致性。** Web 与 CLI 共用执行和后台管理；核心不依赖 React 或页面；不新增 Agent 框架、托管执行或服务端文件能力。默认复用现有依赖。
- **N2：安全优先。** 参数、定义、路径、工具身份和权限在执行前校验；继续遵守工作区真实路径边界、沙箱、受保护文件和凭据脱敏。缓存优化不能弱化权限隔离。
- **N3：资源有界。** 对任务记录、队列、定义输入、迁移内容、摘要和执行时长设置显式边界；清理失败可观察，不把仍在运行的进程标记已回收。
- **N4：确定性与可诊断性。** 状态转换、终态、队列投递与用量可用本地替身验证；真实服务缓存命中不是验收必要条件。仅报告实际执行的验证。
- **N5：兼容性。** 保留现有共享和独立 Skill、Plan/Do、权限、会话恢复和完成验证行为；既有会话可继续打开，子执行记录不被误认为可恢复后台任务。

## 不做的事

- Worktree 或其他文件系统隔离；工作区事务及自动回滚。
- 多 Agent 团队编排、子 Agent 递归委派、成员间通信和任务依赖图。
- 后台任务跨运行时、跨进程或跨会话迁移与恢复；关闭运行时后自动续跑。
- Hook 引擎、插件角色加载、角色在线编辑器、固定模型档位。
- 自建提示缓存或缓存命中保证；后台结果自动触发新模型轮次。
- 自动提交、推送、创建 PR，以及未授权的真实模型评估。

## 验收标准

- **AC1（F1）：** 用同一个工具创建两种任务、选择不同角色，均先取得不同任务 ID；未知类型、角色、模型、非法预算和前台 Fork 在执行前被结构化拒绝，没有替代子运行。
- **AC2（F2）：** 项目、用户、内置同名角色按优先级选择；同层重名、高优先级无效 YAML、非法元信息均有诊断且不回退。运行中改文件不改变已启动角色指令；多次子模型请求和压缩后角色约束仍在。扫描不会启动 MCP 或脚本。
- **AC3（F3、F7）：** 定义式首次请求不含父对话中的标记文本，只含必要背景、角色与任务；子消息、完成报告、授权和取消状态变化不污染父及兄弟实例。
- **AC4（F4）：** 父本轮先完成工具调用再委派，Fork 包含该已完成交换和当前用户输入；同批未完成调用组整体排除。校验所有历史工具调用与结果完整配对，父后续追加对话不改变快照；已有摘要保留且不被声称为原始历史。
- **AC5（F5）：** 父卸载内容可通过子专属引用读取，旧父引用被拒绝或明确不可用；引用缺失、容量超限、损坏配对均不启动子模型、不截短历史，资源被回收。
- **AC6（F6、F19）：** 使用同一兼容配置的 Fork 保留可复用历史顺序和稳定背景，任务增量不会无意义重写前缀；需要权限过滤或引用迁移时优先保证安全。分别注入缓存命中、未命中和缺失 usage，统计准确且三者任务行为一致；不存在字段时显示未知。
- **AC7（F7、N1、N5）：** 重构后既有独立 Skill 的 none/recent/all 历史选择、前台审批、父预算、摘要和取消场景仍成立；主循环和会话创建复用，没有双端各写一套子循环。
- **AC8（F8）：** 父禁用、角色黑名单、白名单交集、Plan 禁写、共享 Skill 限制和权限模式分别生效；子声明更宽松模式不提权。父权限扩大不扩大子上限，撤销影响后续操作，子单次批准不授予兄弟。非交互及后台需审批操作立即结构化拒绝，前台审批显示子任务身份。
- **AC9（F9）：** 子尝试直接委派、伪造管理工具调用、加载独立 Skill、通过共享 Skill 指令调用禁用工具均失败；允许的共享 Skill 能使用权限交集内工具，加载工具豁免不能突破子黑名单。
- **AC10（F10）：** 父轮次结束并完成自身清理后，后台任务仍可使用其上下文及 MCP 租约完成调用；父释放租约不关闭子正在使用的连接。子终态后资源关闭，结果仍可查看；初始化中途失败也无资源泄漏。
- **AC11（F11）：** 显式后台、等待超时、手动转后台三条路径只产生一次子运行和一次受控副作用，任务 ID 与截止时间不变；等待已完成任务立即返回。审批中转后台使待审批请求失效，迟到批准不执行工具。
- **AC12（F12）：** 停止父生成、断开浏览器或结束等待不取消已接纳任务；显式取消排队和运行任务均有效，重复取消与完成竞态只有一个终态。关闭运行时终止全部执行与进程；重启不恢复。清空父会话后旧任务结果不能写入新世代。
