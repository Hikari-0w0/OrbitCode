# Web 人机交互与视觉重构 Spec

状态：已批准
范围更新：2026-10-18 用户明确要求只关注桌面 Web，不再支持手机端；该指示作为本轮范围变更依据。

审批记录：用户于 2026-10-17 明确批准四份文档并授权开始开发。

## 背景

本轮目标是全面优化 OrbitCode 的人机交互和 UI，允许重构，但不得削减功能。

2026-10-17 已只读核对首页、设置页、相关组件、样式、README 和界面测试；开始时 Git 工作区干净。该基线判断来自实现前源码；实施后的浏览器证据见 checklist.md：

- 侧栏同时承载会话、Skills、背景与记忆、过期会话清理、工作区、模型、权限和重复状态，主次关系不清晰。
- 会话使用下拉框，难以浏览历史；设置以长页面集中罗列资源与编辑表单。
- 多处辅助文字为 8–10px；窄屏隐藏部分运行、模式和上下文信息。
- 背景与清理面板含未由当前样式系统提供的工具类，视觉规则不一致。
- 输入不可用时统一提示模型配置不可用，未解释实际阻塞原因；部分管理交互使用浏览器原生确认或输入对话框。
- 已有流式消息、工具时间线、审批、Plan 执行、上下文、Skills、记忆和配置管理，需要完整纳入新界面。

## 目标

- 建立统一、清晰、克制的现代编程工作台，以阅读、输入、执行状态和必要审批为主要视觉层级。
- 重组导航与管理流程，减少拥挤、重复信息和不必要跳转。
- 从首次配置到日常对话、异常恢复与历史管理形成完整闭环。
- 以逐项功能对照、真实浏览器检查和异常场景证明重构没有功能回退。

## 假设与方案选择

- 本轮重构 Web 全部现有页面及交互；CLI 的命令、导出及共享运行语义保持兼容，不另行设计终端外观。
- 中文为主，保留必要技术名词。默认采用中性色、少量品牌强调色、清晰排版和轻量边界；提供浅色、深色及跟随系统外观。
- 不要求复刻特定产品。具体视觉参数和主要页面状态布局在技术计划中确定；本规格不预设组件或实现文件。
- 方案 A：保持布局、统一样式。复杂度低、影响面小，但难以解决侧栏拥挤和配置流程割裂。
- 方案 B（推荐）：重组工作台导航、对话和管理层级，并统一视觉及状态交互。与现有界面调用共享运行时的边界一致；需要完整回归，后续能力也有明确容纳位置。
- 选择 B。可以替换现有前端组织方式，不能借 UI 重构更改权限、安全或 Agent 执行含义。

## 功能需求

- F1：统一信息架构。会话导航、主对话、当前工作环境和管理入口职责清晰。低频管理可折叠或进入专用区域；从工作台至 Skills、背景、清理及设置对应区域不超过两次导航操作。待审批和运行异常不能因收起面板而不可察觉。覆盖 B1–B13。
- F2：统一视觉。全部页面、表单、工具卡、弹层、提示与空状态使用一致的字体层级、间距、颜色和交互反馈。主题可选择并在刷新后保留；无偏好时跟随系统。删除阶段编号等无实际使用价值的装饰信息。
- F3：完整会话管理。以可浏览列表呈现会话，提供标题搜索、选中状态和新建入口；保留 B1 全部操作。重命名使用应用内表单，删除及清空说明影响并可取消。失败保留可恢复的信息，不假装已经成功。
- F4：首次使用与环境选择。明确区分未配置、配置无效、资源停用、会话加载、只读历史和权限会话不可用。提供对应配置或恢复入口，显示当前工作区、模型及生效范围；保持 B2 约束。首次使用无需手工编辑配置文件即可配置并进入可发送状态。
- F5：输入与运行控制。保留 B3，中文输入法确认不得误发送，Enter 发送、Shift+Enter 换行；空白输入不发送，重复提交受控。停止、停止中、成功、失败和取消有明确区别。切换会话及离开存在未保存编辑的区域时，草稿不被静默丢弃。Plan 执行保持原有可执行范围，不执行过期计划。
- F6：可读消息与证据。保留 B4，以摘要和可展开详情降低工具噪声，支持安全呈现常用 Markdown（标题、列表、引用、链接、代码块、表格）、复制消息和代码。流式不完整内容可读，原文可获取；长代码局部滚动。用户查看历史时不强行拉回底部，新增输出提供返回最新入口。不得把模型完成、外部调用成功或所列检查通过改写为全部需求验收通过。
- F7：显著且准确的审批。保留 B5；审批信息与目标工具对应，展示服务端安全摘要，不能默认替用户授权。提交中防重复，失败可重试，过期/已处理请求不可再次操作。永久允许的范围不能被隐藏。权限模式与 Plan/Do 区别清楚。
- F8：上下文、Skills 和记忆管理。保留 B6–B8，全量内容在合适宽度的区域阅读和编辑。加载、空结果、刷新、操作失败和并发冲突可区分；刷新列表不得自动执行 Skill、调用模型或修改记忆。编辑失败保留输入，删除需明确确认。
- F9：安全清理历史。保留 B9。预览先于执行，区分可清理与不可清理项，明确选中数量、不可逆影响与结果；不得绕过原有运行保护、资格判断或批量上限。
- F10：分区配置管理。模型、工作区、MCP、运行偏好与配置恢复有清晰分类，保留 B10–B13。列表与新增/编辑有明确关系；字段有说明和就地校验，成功/失败/保存中可辨识。保留未保存输入及离开提示，凭据仍只展示安全状态；明确设置从下一轮生效。MCP 保存、连接、发现与调用不能合并为隐式授权。
- F11：桌面浏览器与可访问操作。桌面以对话为中心，会话导航固定可见，按桌面窗口宽度调整间距，不提供手机专用抽屉或布局。键盘可操作导航、表单、菜单和审批；弹层管理焦点、关闭后归还焦点，图标按钮有名称，状态不只依赖颜色。
- F12：一致的状态与恢复。配置加载失败、会话冲突、请求断开、保存失败、工具失败、参数无效、超时、取消及轮数上限均显示真实状态和允许的下一步。不把断开显示为停止成功，不以重新执行替代重试保存，不因视图切换重复发送任务；运行中的管理约束与共享运行时保持一致。

## 非功能需求

- N1：功能等价与兼容。B1–B13 每项均须有新入口与行为证据；既有会话、配置和 CLI 可继续使用。不能通过删除测试或弱化断言掩盖回退。
- N2：安全。保持工作目录、权限、凭据脱敏、并发控制、取消和终止边界。消息内容不能执行脚本或任意 HTML；链接禁止危险协议。测试使用隔离数据和本地替身，不使用真实密钥。
- N3：可读性。正文默认至少 14px，辅助说明至少 12px；普通文本对比度至少 4.5:1，交互边界及焦点至少 3:1。主要触控目标至少 44×44px。减少动态效果偏好生效。
- N4：适配。覆盖 1024×768、1280×720、1440×900、1920×1080 的桌面窗口及 200% 缩放；手机端不再列为支持与验收范围。页面不出现整体横向溢出；代码及宽表允许局部滚动；发送、停止和审批不被导航或浮层遮挡。
- N5：流畅性。以 200 条消息、50 条工具记录及长输出为固定浏览器样本，验证连续输入、滚动、详情展开和流式追加。技术计划固定设备条件和性能测量口径，记录优化前后结果，不使用虚构进度百分比。
- N6：工程边界。严格 TypeScript，界面不接管 Agent 核心执行；默认不新增运行时依赖。若 Markdown 等需求确需依赖，在技术计划说明现有方案不足和安全取舍后审批。
- N7：验证。相关回归与 lint、typecheck、build 均须执行；以 agent-browser 检查页面、错误覆盖层及控制台，以 tmux 和安全本地替身覆盖完整 Agent 对话与异常路径。检查结束清理测试进程。替身通过不代表真实模型能力通过。

## 不做的事

- 不再维护手机专用布局和手机导航抽屉；桌面 B1–B13 功能继续保留。

- 不新增文件编辑器、终端模拟器、Git 面板、多智能体编排、云同步、账号系统或新的模型协议。
- 不重设计 Agent 算法、工具能力、权限政策、长期记忆策略及持久化协议；已有能力的展示与操作优化在范围内。
- 不自动连接外部 MCP、不发起真实付费模型评测、不提交、推送或部署。
- 按本轮最新指示，一次性提供需求规格、技术计划、任务和验收清单草案；四份文档批准前不编写实现代码。

## 验收标准

- AC1（F1，N1）：逐项对照 B1–B13，为每个操作记录新入口和结果；无遗漏、无仅剩展示但不能操作的入口；低频管理满足两次导航上限，打开管理区域时仍可发现待审批。
- AC2（F2，N3）：对话空态、长对话、工具失败、审批、设置和管理区域在三种主题选项下表现一致；刷新保留选择，系统主题可跟随；检查字体、对比度、交互状态与动效偏好并保留截图证据。
- AC3（F3）：建立多个会话，完成搜索、新建、切换、改名、取消删除、确认删除、清空和导出；只读历史仍可查看与导出；失败不丢失当前可恢复信息。
- AC4（F4）：在无配置的隔离环境完成模型与工作区配置后进入可发送状态；分别模拟无效/停用配置、加载和只读状态，界面准确解释阻塞原因并给出可用入口。
- AC5（F5）：验证中文输入法、换行、空白输入、重复点击、流式、停止及停止中；产生计划并执行最新可执行计划，旧计划不误触发；会话切换与离开编辑区不会静默丢失草稿。
- AC6（F6，N2、N5）：呈现含 Markdown、长代码、工具交错和不完整流片段的固定长会话；顺序、复制、原文、Token、耗时和终止信息正确；历史阅读不被打断；恶意 HTML/链接不执行；检查证据文案不扩大含义。
- AC7（F7）：逐一验证三种权限模式、四种决定、提交失败重试、过期和重复决定；运行中审批在支持的桌面窗口中均可发现，安全摘要与授权范围完整且未泄露凭据。
- AC8（F8）：分别执行压缩成功/失败/熔断恢复、Skill 刷新/带参数调用/停用、背景检查、记忆开关/查看/编辑/删除；验证空态、失败和冲突；单纯查看或刷新不引起额外执行。
- AC9（F9）：预览包含合格、不合格和运行中会话的候选；验证选择数量、限额、取消/确认删除、部分失败反馈和当前会话状态协调，不误删不合格记录。
- AC10（F10）：逐项执行 B10–B13；验证新增/编辑取消、校验、保存失败、并发冲突和未保存离开；MCP 保存不连接，显式连接可取消并展示发现结果；凭据不回显，生效时机明确。
- AC11（F11，N3、N4）：在规定尺寸和缩放下以鼠标及键盘走通新建、发送、停止、审批和设置；检查焦点可见、弹层关闭及归还、读屏名称、状态播报、无整体溢出与功能遗漏。
- AC12（F12，N1、N2、N7）：用隔离场景覆盖配置异常、断流、冲突、未保存轮次、工具失败、参数无效、超时、取消和最大轮数；恢复操作与运行记录一致，不重复执行。CLI 回归、浏览器检查及规定工程检查通过，未执行项明确列为未验证。

- 当前结论是源码调研结果，未宣称视觉或端到端验收已通过。
