## 需求验收

- [x] C1 — AC1 / F1、F15、N1–N3：从正常 Web Agent、伪造客户端提交和底层工具调用三条路径请求文件与命令工具，只有经统一服务端权限网关最终允许的调用执行；等待或拒绝时目标、进程和配置均无变化。（验证：权限网关/Route 集成测试；检查核心权限模块无 React/Next.js 导入）
- [x] C2 — AC2 / F2、F14、N5、N9：对危险操作的直接、参数、链式、子 shell 与静态包装变体分别配置 allow、切换 permissive、尝试人工允许，均在进程启动前得到 `dangerous-operation`，随后模型能调整方案或解释结果。（验证：`dangerous-command.test.ts`、Agent Loop 假工具测试，进程启动替身计数为 0）
- [x] C3 — AC3 / F3、F4、F14、N9：普通路径、绝对路径、`..`、同前缀相邻目录、内部/外部符号链接、符号链接链和缺失写入目标的结果符合边界；命令 cwd/子进程也不能越界，拒绝为 `workspace-boundary` 且无副作用。（验证：Workspace、文件工具、Seatbelt 与网关测试，使用临时目录和哨兵文件）
- [x] C4 — AC4 / F5、F6、N4：三层配置中的精确、命令 Glob、路径 Glob 和不匹配规则产生确定结果；缺失配置为空集合；重复键、alias、未知工具/字段/决策、非法括号/通配符和超限配置在工具执行前安全失败。（验证：规则与权限配置单元测试）
- [x] C5 — AC5 / F7、N3、N5：跨层级、不同顺序和不同具体度的所有 `allow/ask/deny` 组合始终满足 `deny > ask > allow`，公开原因只含安全层级与决策摘要。（验证：表驱动合并测试，覆盖三决策非空子集和顺序置换）
- [x] C6 — AC6 / F8、F9、N7：无匹配时，strict 对全部工具询问，default 只允许只读并询问写入/命令，permissive 默认允许全部；Plan 写入/命令在三模式下始终拒绝，非法客户端模式不改变服务端状态。（验证：评估器、ModeToolPolicy、权限会话 API 与浏览器模式切换）
- [x] C7 — AC7 / F10–F12、F17：页面显示唯一请求、工具名、安全参数、风险、Workspace、来源、持久层级与过期时间；四种决定分别产生正确作用域。重复、过期、跨会话/Workspace、参数不一致和未知决定不能执行工具。（验证：会话管理器、Web 合约、组件和浏览器交互测试）
- [x] C8 — AC8 / F11、F16、N7：无其他匹配规则时永久允许原子新增本地级精确 allow，重载后同一目标不再询问；仍有 ask 时当前调用继续但 UI 提示后续仍询问；不可写、symlink、并发修改和 rename 失败时配置有效且原工具不执行。（验证：真实临时文件配置测试与浏览器提示）
- [x] C9 — AC9 / F12、F13、N6：同一模型响应的多个 ask 按 sequence 逐项处理，只有各自获准项执行；等待时停止、清空、切换 Workspace/Provider、断开页面和关闭会话都会使请求失效，迟到决定无效且无 timer/listener/进程残留。（验证：调度器、会话 TTL/Abort 测试与浏览器网络观察）
- [x] C10 — AC10 / F14、F15：危险操作、路径越界、显式 deny、用户拒绝和已绑定授权复检失效均返回可区分、`sideEffect: none` 的工具失败；除取消外，模型收到结果后能改用安全调用或给出最终文本。（验证：Agent Loop 集成与 Web E2E，断言唯一 stopped）
- [x] C11 — AC11 / F17、N4、N5：桌面与窄屏正确展示权限模式、等待卡、四种决定及所有终态，键盘可操作，无错误覆盖层或控制台错误；DOM、SSE、API 响应和提示不含凭据、正文、受保护内容、绝对路径或堆栈。（验证：真实浏览器、网络/控制台检查和哨兵断言）
- [x] C12 — AC12 / N8–N10：没有新增被禁止框架、托管执行能力或未经批准依赖；既有 Agent Loop、Plan/Do、Workspace、工具、Seatbelt、Provider、取消和 SSE 回归测试继续通过。（验证：依赖差异、导入边界检查和完整测试）
- [x] C13 — AC13 / 全部需求：完整测试、Lint、类型检查和构建成功；临时 Workspace 中完成五层防御、四种决定、拒绝后恢复、取消等待和持久规则重载，结束后关闭浏览器、服务器与相关进程且证据不含真实凭据。（验证：项目检查、浏览器和 tmux 端到端记录）

## 集成与架构

- [x] I1 — 权限依赖方向：`src/core/permissions/` 不导入 React、Next.js、页面组件或 Route；组件不导入文件系统、命令沙箱、配置仓储或工具执行实现。（验证：`rg` 导入检查、`npm run typecheck`、生产构建）
- [x] I2 — 单一执行入口：Tool Registry 准备调用后，调度器必须经 PermissionGateway 才能调用 execute；六个工具只声明权限目标元数据，不包含规则、模式或审批分支。（验证：注册中心与网关集成测试、结构检查）
- [x] I3 — 两阶段不变量：Schema 只解析一次，单次授权绑定完整参数指纹；会话/永久授权绑定工具与规范目标；人工允许后的复检发生在 tool-started 之前。（验证：Registry、Gateway 和 Scheduler 事件顺序测试）
- [x] I4 — SSE/HTTP 恢复：permission-requested 到达后原聊天 SSE 保持打开，独立决定请求解析原服务端等待项，permission-resolved 后原 Agent Loop 继续而非重新创建或重放。（验证：`tests/web-permission-agent.e2e.test.ts` 与浏览器网络时间线）
- [x] I5 — 调度语义：连续立即允许的只读调用仍按上限并发；ask、写入和命令是串行边界；模型收到的工具结果顺序与调用 sequence 一致。（验证：调度器并发时序测试）
- [x] I6 — 会话事实来源：权限模式、Workspace/Provider 绑定、会话授权和等待项只保存在服务端会话；浏览器历史、模型文本和客户端参数均不能伪造。（验证：会话 API 伪造与跨会话测试）
- [x] I7 — 既有安全层兼容：路径预检、敏感路径、原子文件写入、Seatbelt、网络禁用、环境过滤、工具超时、最大迭代和 sideEffect 聚合均继续生效。（验证：既有相关测试和一个完整 Agent 工具轮）

## 安全与异常路径

- [x] S1 — 路径包含使用 `path.relative` 与规范真实路径，不存在字符串前缀授权；`/workspace` 与 `/workspace-escape` 类同前缀目录不能混淆。（验证：临时目录单元测试）
- [x] S2 — 请求路径与规范目标都检查受保护文件；通过内部 symlink 指向权限配置或敏感文件也被拒绝，搜索遍历不返回这些文件。（验证：Workspace/搜索测试）
- [x] S3 — 项目/本地权限 YAML 对文件工具与 Seatbelt 命令不可读写；用户级配置位于 Workspace 外；服务端配置仓储仍可读取与原子更新本地层。（验证：文件工具、搜索、Seatbelt 和仓储集成测试）
- [x] S4 — 危险命令规则来自代码常量，任何 YAML、权限模式、会话或人工决定都无覆盖入口；分析超限或高风险动态形式失败关闭。（验证：规则组合与扫描限制测试）
- [x] S5 — 配置解析限制 256 KiB、每层 512 条、合并 1536 条，拒绝 alias、重复键和未知字段；Glob 匹配有长度与复杂度边界。（验证：边界值与超限单元测试）
- [x] S6 — 永久写入检查父目录与文件 symlink、预期身份和并发冲突，临时文件同步后原子 rename；所有失败路径清理临时文件且不授予当前工具。（验证：注入失败的仓储测试）
- [x] S7 — 畸形、未知或跨会话决定 API 返回安全 4xx 且不改变等待项；已绑定等待项在恢复复检失效时返回 `approval-invalid`，模型可调整。（验证：Route、会话管理器和 Agent 集成测试）
- [x] S8 — 请求取消、等待过期、会话 close、空闲 TTL 和服务重启语义均不会留下可被迟到提交唤醒的等待项。（验证：注入时钟/AbortSignal 测试、进程重启观察）
- [x] S9 — 服务端审批摘要隐藏写入/替换正文、疑似凭据和绝对路径；长命令截断并脱敏，生成摘要失败时使用最小摘要。（验证：presentation 单元测试与浏览器哨兵扫描）
- [x] S10 — 权限拒绝、工具失败、命令非零退出、超时和取消保持结构化结果；服务无未处理 Promise、僵尸进程、部分配置写入或无法继续对话状态。（验证：错误注入测试与后续合法请求）
